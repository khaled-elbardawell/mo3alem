# نرد - Responsive Wheel UI V2

تحديثات هذه النسخة:
- الإعلان العلوي والجانبي أصبحوا صور `<img>` داخل رابط كامل `<a>`.
- إضافة تبويبات: وضع الضيف / وضع الحفظ.
- تبويبات اللوحة: البيانات / النتائج.
- النتائج تسجل الفائزين تلقائيًا بالترتيب بعد كل لفّة.
- إصلاح مسح البيانات من الواجهة.
- احتفال عند ظهور الفائز + صوت احتفالي باستخدام Web Audio API.
- تحسين الريسبونسيف وإضافة قائمة موبايل تعمل.
- استخدام Font Awesome للأيقونات.
- حذف زر الإعدادات.
- العجلة تعمل zoom حسب عدد الأسماء:
  - عدد قليل: قطاعات أكبر وخط أوضح.
  - عدد كبير: زوم أوت ورسم أخف حتى يتحمل آلاف الأسماء.
- القائمة Virtualized لتحمل 2000+ اسم بدون بطء.
